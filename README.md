## 🛠️ Troubleshooting / Fix Workflow

1. Install 1.0.4 or a newer build before comparing against launch-era stutter reports.
2. Record your CPU, GPU, RAM, display resolution, game version, world size and player count.
3. Choose one repeatable scene at the base and measure FPS/frame-time in the same place twice.
4. Lower resolution or GPU-heavy visual settings one at a time; compare each result rather than changing everything.
5. Check Windows graphics drivers, background overlays and competing CPU/GPU workloads.
6. Repeat the same test away from active robot fleets and conveyors to identify base-size load.
7. Keep the result that improves frame pacing and re-test after the next patch.

## ❓ FAQ

**Does this guarantee a higher FPS?**  
No fixed FPS uplift can be guaranteed; patch and hardware determine performance.

**Was tool-switching freezing fixed?**  
The developer lists it as fixed in 1.0.4 when many robots are operating.

**Should I change every graphics option at once?**  
No. One variable at a time makes comparisons meaningful.
